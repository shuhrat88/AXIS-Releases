# Политика безопасности

## Сообщить об уязвимости

Используйте приватное сообщение: вкладка **Security → Report a vulnerability** этого репозитория (GitHub Security Advisories).
Не публикуйте детали в открытых issues.

## Ключ подписи обновлений

- Алгоритм: Ed25519. Публичный ключ (32 байта, base64):
  `IOxNR1o/RvLSMRoG5wat1tOWKsZwLT8LJO39qDfn1Rg=`
- Отпечаток: SHA-256 публичного ключа, первые 16 hex-символов: `c1c3ff894db6ff5a`.

Этот ключ зашит в программу. Манифест обновления без подписи этим ключом не принимается.
Приватный ключ хранится только у владельца проекта вне репозиториев и сборок.
