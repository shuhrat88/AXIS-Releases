# Changelog

## 1.0.0

Первый публичный выпуск AXIS для Windows x64.

- Установщик `AXIS_Setup_v1.0.0.exe`: без прав администратора, данные пользователя в `%LOCALAPPDATA%\AXIS`.
- Офлайн-распознавание речи (GigaAM v3 CTC, Silero VAD) — модели устанавливаются с установщиком и проверяются по SHA-256.
- Остров AXIS (WPF): чат с ответами в Markdown, копирование ответов, история диалога с подгрузкой по прокрутке.
- Уровни доступа к компьютеру: «Наблюдатель», «Ограниченный» (по умолчанию), «Расширенный», «Полный».
  Штатное закрытие обычных приложений выполняется без вопроса на уровнях «Ограниченный» и выше;
  системные процессы, принудительное завершение и массовое закрытие не выполняются.
- Журнал действий ассистента: только название инструмента, уровень, решение и результат. Значения аргументов не записываются.
- Обновления: проверка подписанного манифеста Ed25519, SHA-256 установщика, подтверждение перед загрузкой и установкой, защита от понижения версии.
