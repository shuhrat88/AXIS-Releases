# AXIS: установщик и обновления

Этот репозиторий публикует только установщик AXIS, манифесты обновлений, контрольные суммы и документацию для пользователей.
Исходный код AXIS в этом репозитории не публикуется.

## Установка

1. Откройте страницу последнего релиза и скачайте `AXIS_Setup_v<версия>.exe`.
2. Проверьте SHA-256 файла по значению из `SHA256SUMS.txt`:
   `Get-FileHash .\AXIS_Setup_v<версия>.exe -Algorithm SHA256`
3. Запустите установщик. Права администратора не нужны: программа ставится в `%LOCALAPPDATA%\Programs\AXIS`.

Данные пользователя хранятся отдельно, в `%LOCALAPPDATA%\AXIS`: настройки, память, журналы и ключи API.
Они не удаляются при обновлении и при удалении программы.

## Обновления

- AXIS проверяет наличие новой версии автоматически: при запуске и затем раз в сутки.
  Проверка обращается к GitHub (адрес манифеста в этом репозитории) и передаёт обычные сетевые данные этого запроса.
  Отключить автопроверку можно переменной окружения `AXIS_UPDATE_AUTOCHECK=0`.
- Манифест обновления подписан Ed25519. Программа проверяет подпись встроенным публичным ключом, затем SHA-256 установщика.
- Скачивание и установка выполняются только после вашего подтверждения.
- Понижение версии не предлагается.

Публичный ключ и его отпечаток указаны в `SECURITY.md`.

## Удаление

Удалите AXIS через «Параметры → Приложения». Папка `%LOCALAPPDATA%\AXIS` с вашими данными остаётся;
удалите её вручную, если данные больше не нужны.
